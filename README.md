## ABOUT THE REPOSITORY
This is just a personal portfolio reposity created with react js, node js, mongo and nodemailer.

## TECHSTACK
### Frontend
- React js
- Framer Motion
- React Hot Toast

### Backend 
- Node js
- Express js
- Mongo db
- $${\color{blue}Morgan}$$
- nodemon
- nodemailer

## INSTALLATION
```
CLONE THE REPOSTITORY
git clone repo

FRONTEND
cd app
npm run install
npm run dev

BACKEND
cd server
npm install
npm run start

```
